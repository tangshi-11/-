# 员工预估公司风险 · 项目框架

> 在线版：[飞书框架文档](https://feishu.doubao.com/docx/U5jSdYlnMoFPUdxyZPAcD40Ynic)（实时协作，可编辑）

## 1. 项目定位与核心设计

**项目目标**：为员工、求职者和投资合作方提供一套可操作的公司风险预判方法，回答四个问题——这家公司有没有钱、守不守约、扛不扛得住、别人怎么看它。

**为什么用信号灯而不是加权总分**：加权总分存在结构性缺陷，一个强风险信号（如存贷双高）会被其他正常指标稀释，总分仍可能及格。信号灯机制将风险分成两类：一类是"一票否决"的硬信号，任一命中直接判高危；另一类是"累积评分"的软信号，按行业基准逐项计分。

## 2. 框架总览：四层信号灯

```
数据输入 A（公开数据·自动抓取）    数据输入 B（内部信号·人工采集）
         ↓                                    ↓
┌──────────────────────────────────────────────────────┐
│ L1 红灯 · 一票否决（任一命中 = 高危）                      │
│ 非标审计意见 | 失信/限高 | 监管立案 | 资不抵债 | 存贷双高    │
├──────────────────────────────────────────────────────┤
│ L2 黄灯 · 量化评分（行业分位数校准 + 看2-3年趋势）            │
│ 现金流质量 | 偿债能力 | 盈利质量 | 应收/存货质量             │
├──────────────────────────────────────────────────────┤
│ L3 黄灯 · 定性信号（治理 + 舆情）                          │
│ 质押减持 | 关联交易 | 处罚问询 | 关键人事 | 担保 | 高息融资  │
├──────────────────────────────────────────────────────┤
│ L4 人工 · 员工专属观察（最准，只能人工）                     │
│ 欠薪 | 社保欠缴 | 裁员补偿 | 招聘冻结 | 办公收缩            │
└──────────────────────────────────────────────────────┘
         ↓
输出：风险等级（绿/黄/红） + 关键风险清单 + 员工行动建议
```

## 3. 指标体系详解

判定规则中的阈值均为行业校准后的参考值，实际使用时须与同行业公司对比，不直接套用固定线。

### 3.1 L1 红灯 · 一票否决

| 指标 | 看什么（口径） | 数据来源 | 判定规则 |
|---|---|---|---|
| 审计意见 | 年报审计报告的意见类型 | 巨潮资讯、交易所公告 | 保留、无法表示、否定意见 → 直接红灯 |
| 失信与限高 | 是否列入失信被执行人、限制消费名单 | 中国执行信息公开网 | 任一命中 → 直接红灯 |
| 监管立案调查 | 证监会、交易所立案公告（区别于一般处罚） | 证监会、交易所官网 | 被立案 → 直接红灯 |
| 资不抵债 | 负债总额超过资产总额 | 年报资产负债表 | 连续两期 → 直接红灯 |
| 存贷双高 | 货币资金高＋有息负债高＋利息收入与存款不匹配 | 年报三表勾稽 | 双高且利息异常 → 直接红灯（康美、康得新爆雷特征） |

### 3.2 L2 黄灯 · 量化评分

| 指标 | 看什么（口径） | 数据来源 | 判定规则 |
|---|---|---|---|
| 现金流质量 | 经营现金流／净利润（含金量）、收现比＝销售收现／营业收入 | 年报现金流量表＋利润表 | 低于行业分位数且连续恶化 → 计分 |
| 偿债能力 | 资产负债率、流动比率、速动比率、利息保障倍数 | 年报资产负债表 | 与同行业分位数比较，不设固定线 |
| 盈利质量 | 利润与现金流匹配、毛利率趋势、费用率结构 | 年报利润表＋现金流量表 | 收入涨利润不涨须拆分费用结构后再判 |
| 应收与存货 | 应收账款周转天数、账龄结构、存货周转 | 年报附注 | 周转突然恶化、账龄拉长 → 计分 |

### 3.3 L3 黄灯 · 定性信号

| 指标 | 看什么（口径） | 数据来源 | 判定规则 |
|---|---|---|---|
| 质押与减持 | 大股东质押比例、高管减持公告 | 交易所公告、巨潮资讯 | 高比例质押＋密集减持 → 计分 |
| 关联交易 | 关联交易金额／营业收入、定价公允性 | 年报关联交易章节 | 金额大且定价不公允 → 计分 |
| 处罚与问询 | 监管处罚公告、年报问询函频次 | 交易所、证监会官网 | 频繁收到 → 计分 |
| 关键人事变动 | 独董、审计师、财务总监非正常离职 | 公司公告 | 财务背景独董辞职 → 强信号 |
| 对外担保 | 担保净额／净资产比例 | 年报担保章节 | 比例超过 50% → 计分 |
| 高息融资 | 信托、租赁、债券融资成本 | 年报负债附注 | 融资利率显著高于市场 → 计分 |

### 3.4 L4 人工 · 员工专属观察

| 指标 | 看什么（口径） | 数据来源 | 判定规则 |
|---|---|---|---|
| 工资发放 | 是否按时、足额发放 | 个人经历、同事信息 | 延迟、分批发放 → 高危信号 |
| 社保公积金 | 是否足额、按时缴纳 | 个人账户查询 | 欠缴、断缴 → 高危信号 |
| 裁员补偿 | 裁员是否依法赔偿 | 内部信息、脉脉、看准网 | 不赔偿、变相逼退 → 经营困难佐证 |
| 招聘与编制 | 招聘冻结、HC 缩减、offer 撤回 | 内部信息、招聘平台 | 收缩 → 黄灯 |
| 办公收缩 | 换小办公室、撤点、搬迁 | 内部信息 | 收缩 → 黄灯 |

## 4. 评分与判定规则

判定按固定顺序执行：**先扫描红灯 → 再计黄灯分 → 最后叠加人工信号**。

- **红灯命中即终止**，不进入计分，直接输出"高危"并列出命中项。
- 单一指标只是"信号"，须有 2 项以上同向证据才升级判定，避免单点误判。
- **等级含义**：
  - **绿**：财务与治理正常，可正常入职或继续在职观察。
  - **黄**：存在值得跟踪的风险点，保持警惕并按季度复查。
  - **红**：存在致命风险或资金链断裂迹象，应慎重入职、尽快准备替代方案。
- 所有结论必须注明证据类型（公开数据或内部信号）与时间范围。

## 5. 数据源与获取方式

### 5.1 可自动抓取的公开数据（合规源）

| 数据源 | 网址 | 可查内容 | 说明 |
|---|---|---|---|
| 巨潮资讯网 | cninfo.com.cn | 年报、公告、问询函 | 上市公司披露总入口 |
| 沪深交易所官网 | sse.com.cn / szse.cn | 问询函、监管函、立案公告 | 官方监管信息 |
| 中国执行信息公开网 | zxgk.court.gov.cn | 失信被执行人、限制消费 | 查询无门槛 |
| 信用中国 | creditchina.gov.cn | 行政处罚、失信记录 | 覆盖企业主体 |
| 国家企业信用信息公示系统 | gsxt.gov.cn | 工商信息、经营异常名录 | 有验证码门槛 |
| 裁判文书网 | wenshu.court.gov.cn | 涉诉记录 | 部分文书已下架 |

抓取时遵守各站点 robots 协议与访问频率限制。

### 5.2 必须人工采集的内部信号

工资发放、社保缴纳、裁员补偿、招聘动态、办公收缩五类信号没有公开数据源，只能通过个人经历、同事沟通、脉脉与看准网等渠道人工采集。它们是员工场景准确度最高的信号，应作为判定中的优先证据。

### 5.3 合规红线

- 不爬取企查查、天眼查等商业平台：存在反爬机制和版权风险，抓取行为可能违法。
- 不采集个人隐私信息；员工评价类信息仅作人工参考，不批量存储。
- 自动抓取仅限官方公开来源，且控制访问频率。

## 6. 输出与应用

评估结果按统一模板输出，方便横向比较多家公司：

1. **风险等级**：绿／黄／红，附判定依据摘要。
2. **关键风险清单**：命中项、证据类型（公开／内部）、证据时间、影响程度。
3. **行动建议**：入职前——是否接受 offer、如何谈判；在职中——是否提前准备跳槽、保留哪些证据。

## 7. 验证与迭代计划

### 7.1 用爆雷案例回测

| 案例 | 爆雷前 1-2 年应出现的信号 | 对应层级 | 是否捕捉 |
|---|---|---|---|
| 康美药业 | 存贷双高、货币资金造假 | L1 | 待验证 |
| 康得新 | 存贷双高、问询函频繁 | L1、L3 | 待验证 |
| 恒大集团 | 高息融资、受限资金占比高、商票逾期 | L2、L3 | 待验证 |
| 蛋壳公寓 | 欠薪、裁员、租金贷争议、负面舆情 | L3、L4 | 待验证 |

### 7.2 迭代路径

1. **阶段一（框架定稿）**：完成框架评审，明确各指标阈值与计分权重。
2. **阶段二（回测校准）**：对回测案例逐项评分，调整误判指标与阈值。
3. **阶段三（工具化）**：搭建合规抓取管道与评分脚本，输出自动化评估。
4. **阶段四（试运行）**：选取 3-5 家真实公司试跑，与公开评级交叉验证。

## 8. 结论与边界

**核心结论**：员工预估公司风险应优先盯"一票否决"硬信号和员工内部信号，量化指标一律按行业校准并看趋势。

**边界**：公开数据主要覆盖上市公司，非上市公司只能依赖工商、司法与人工信号，评估完整性受限；年报数据存在披露滞后，结论仅代表截至数据时间的风险状态，不构成对未来的确定性预测。
