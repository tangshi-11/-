# 员工预估公司风险评估框架

一个面向员工、求职者和合作方的公司风险预判工具：评估目标公司"有没有钱、守不守约、扛不扛得住、别人怎么看它"，输出风险等级与行动建议。

**核心设计：四层信号灯** —— 红灯一票否决，黄灯按行业校准累计，员工内部信号优先级最高。不用加权总分，避免平均分掩盖爆雷。

## 框架总览

| 层级 | 定位 | 内容 |
|---|---|---|
| L1 红灯 | 一票否决，任一命中即高危 | 非标审计意见、失信/限高、监管立案、资不抵债、存贷双高 |
| L2 黄灯 | 量化评分，按行业分位数校准 | 现金流质量、偿债能力、盈利质量、应收/存货质量 |
| L3 黄灯 | 定性信号（治理 + 舆情） | 质押减持、关联交易、处罚问询、关键人事、对外担保、高息融资 |
| L4 人工 | 员工专属观察，最准但只能人工 | 欠薪、社保欠缴、裁员补偿、招聘冻结、办公收缩 |

完整指标口径、判定规则与数据源见 [docs/framework.md](docs/framework.md)，在线版见[飞书框架文档](https://feishu.doubao.com/docx/U5jSdYlnMoFPUdxyZPAcD40Ynic)。

## 快速开始

**网页版（推荐，零安装）**：直接双击打开 `web/公司风险信号灯评估.html`，浏览器即可使用——录入指标 → 一键评估 → 输出风险等级。

**命令行版**：需要 Python 3.8+，纯标准库，无第三方依赖。

```bash
# 用示例数据评估
python src/cli.py data/sample_company.json

# 自建数据：复制 data/sample_company.json，按注释修改指标值后运行
```

## 数据来源

公开数据仅使用官方合规源：巨潮资讯网、沪深交易所、中国执行信息公开网、信用中国、国家企业信用信息公示系统、裁判文书网。不爬取企查查/天眼查等商业平台。员工内部信号（工资、社保、裁员、招聘、办公）只能人工采集。
